# CrowdLab

[Open CrowdLab](https://fionviber.github.io/CrowdLab/)

Adjust room layouts, walls and exits, run crowd simulations, inspect throughput and export results.

Open the link to start. No account or password is required. The supplied page is published unchanged as `index.html`.

## Run locally

Download `index.html` and open it in your browser.
